# Somendra Chatterjee — Portfolio

## Local testing
Extract the complete combined ZIP. Open LOCAL-TESTING/START-HERE.html or LOCAL-TESTING/index.html in your browser. No installation or server is required. Keep the assets folder beside index.html.

## GitHub upload
Upload the CONTENTS of GITHUB-UPLOAD into the root of your existing Portfolio repository. index.html must sit at the repository root, not inside an enclosing folder. Upload the assets folder, both CSS files and both JavaScript files as well. Keep your existing Pages configuration. Do not upload the ZIP itself. Your live site is unchanged until you upload these files.

## PDF behaviour
PDF viewing uses the browser's built-in PDF support and settings. Browsers set to download PDFs may download instead. A local or mobile browser may offer a PDF app or Save/Share menu. No custom viewer or external PDF service is used.

## Future resume updates
